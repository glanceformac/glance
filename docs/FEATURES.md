# Glance for Mac: feature guide

The detailed reference for every feature. For installing, see the [README](../README.md).

Glance is a black pill at
the top centre of the screen, over the menu bar. Hover over it (or click it) and it springs open
into a wide panel with your media, weather, calendar, a focus timer, a clipboard and a shelf.
Small "peeks" drop down from the pill for things like charging, app launches, timers and Claude Code.

Native Swift and SwiftUI, built with Swift Package Manager (Command Line Tools only, no Xcode).
Everything it uses is free; no Apple developer account is needed.

## What it does

**Closed pill** (~200 × 32 pt): when something is playing, tiny album art on the left and a small
audio-bar visualiser on the right, tinted with the artwork's colour. While the focus timer runs and
nothing is playing, it shows the countdown instead.

**Expanded panel** (~640 × 236 pt; Clipboard tab is taller): opens with a spring animation that
morphs the pill's shape. It closes shortly after the pointer leaves.

- Top row: Settings, Apps (Launchpad), Edit layout, Volume, Brightness, Theme switch,
  a **Home | Clipboard | Shelf** switch, and quick-launch app icons (editable in Settings).
- **Home** cards:
  - **Now Playing**: artwork, title and artist, progress, previous / play-pause / next. Hidden when nothing is playing.
  - **Weather**: temperature, city, condition symbol, high and low (Open-Meteo).
  - **Calendar**: weekday and date, plus your next event today or tomorrow.
  - **Timer**: 25:00 focus timer (length set in Settings) with play/pause and reset; a peek and a sound when it finishes.
  - Under the cards: a karaoke-style lyrics line (current line bold, next line grey) and shortcut chips
    (YouTube, Messages, Clipboard, Recents, Downloads; Mail, Notes and Screenshot can be added).
- **Edit mode** (sliders icon): cards wiggle and get a "–" badge to hide them. Reorder with the
  arrows or by dragging one card onto another. **Add** brings back hidden cards and adds shortcut
  chips. The layout is saved in UserDefaults.
- **Volume / Brightness** icons swap the cards for a large slider.
- **Theme** (half-circle icon): one click switches the island between Dark Matte and White Matte
  and also switches macOS Light/Dark mode (through System Events; macOS asks once for Automation
  permission). It can also swap your wallpaper between two images you choose in Settings. That
  option is off by default, and Glance only changes which image is shown; it never deletes anything.

**Clipboard tab** (also opens with ⌃⌥V or the Clipboard chip):
- Keeps the last 50 things you copy: text, links, images, and file copies (as references to the
  files, not copies of them).
- **Saved** snippets sit at the top and stay until you delete them. Pin any history item, or make
  a new one with **New Snippet**. Saved snippets can be renamed, reordered and deleted.
- Click an item to copy it back (a "Copied" peek confirms). Optionally, Glance can also paste it
  into the front app; this needs Accessibility permission and is off by default.
- Search box, delete single items, and **Clear History** (asks for a second click; Saved items are not touched).
- Privacy: it never stores items marked concealed, transient or auto-generated
  (`org.nspasteboard.ConcealedType` / `TransientType` / `AutoGeneratedType`). It ignores anything
  copied while a password manager is the front app (1Password, Bitwarden, Keychain Access,
  Passwords, LastPass, Dashlane, Enpass, KeePassXC, Keeper, NordPass, Proton Pass). Data stays on
  this Mac in `~/Library/Application Support/Glance/` (folder 0700, files 0600). History can be
  paused in Settings. It checks the pasteboard's change counter every 0.5 s; that is one integer
  comparison, so the cost is negligible.

**Shelf tab** (a holding tray):
- Drag files, images, text or links near the island: it opens and shows a drop zone. Drop them there.
- Items stay on the Shelf (also after restarts) until you remove them. Drag them back out into any
  app or folder. Click to open; right-click for Quick Look, Show in Finder, or Remove. **Clear All** asks for a second click.
- Files are kept as references (macOS bookmarks), not copies. If you move or rename the original,
  the Shelf follows it; if you delete it, the tile shows "Missing". Removing a tile never touches
  the original file. Images or text dropped without a file behind them (for example from a
  browser) are stored privately in `~/Library/Application Support/Glance/shelf-images`.

**Peeks** (~2.5 s drop-downs from the pill):
- "Notes opened" (with the app icon) when you launch a normal app. Rate-limited: at most one every
  4 s, and the same app at most once a minute.
- Charging / on battery with the percentage, plus low-battery warnings at 20% and 10% (IOKit power-source notifications).
- Focus / Do Not Disturb on and off, on a best-effort basis (see "Known limitations").
- Timer finished, Claude Code done, Claude waiting for input.

**Claude Code** (optional; nothing is installed for you; see `INSTALL-HOOKS.md`):
- When Claude Code needs permission, Glance shows "Claude needs your OK" with the full command or
  tool input (scrollable, never cut off), the project folder name, and **Allow (⌃⌥Y)** / **Deny (⌃⌥N)**.
- Never auto-allows. If you don't answer within about a minute, or if Glance isn't running, Claude
  Code asks in the terminal as usual.
- A green "Done" peek shows the project name and how long the turn took.

**Developer page** (terminal icon in the top row; Settings › Developer):
- **Claude**: Claude Code usage for the current 5-hour session and the week (rolling 7 days, or a
  reset day and hour you choose), time until reset, an on-pace projection, input / output / cache
  write / cache read tokens, prompts, API calls and an estimated API-equivalent cost (Anthropic
  list prices). Plan limits are not stored on the Mac, so pick your plan (Pro, Max 5x, Max 20x) and
  adjust the token or prompt budgets in Settings; every percentage is labelled an estimate.
  Peeks at 80% and 95% (once per window). An optional Home card shows the same at a glance.
  Glance reads only `~/.claude/projects/**/*.jsonl` (the `usage` numbers and timestamps of
  assistant messages, and which lines are typed prompts), incrementally: it remembers each
  file's offset and parses only new lines on a background queue. It keeps numbers only (no message
  text) in `~/Library/Caches/Glance/claude-usage-cache.json`. It never reads
  `~/.claude/.credentials*` or the keychain. Refresh: every 60 s while a usage view is open or a
  threshold is near, otherwise every 15 minutes and a few seconds after each Claude Code turn
  (Stop hook); nothing while the screen sleeps or when it is turned off. The first read of a
  large history takes a few seconds (about 3 GB in 9 s on an M1); later reads take milliseconds.
- **Terminal**: one-line command runner (`zsh -lc`) with an output view, history (up / down),
  Ctrl-C or Stop to interrupt (a second press kills it) and a folder picker. It only runs when you
  press Return or Run, never automatically, and refuses while the island is hidden or closed.
  No interactive input (stdin is empty); output is kept in memory only.
- **Homebrew**: lists `brew outdated` (only if `/opt/homebrew/bin/brew` exists; listing never
  auto-updates). Read-only by default. With "Allow Homebrew upgrades" on, you can upgrade one
  package or all, each after an explicit confirmation, with live progress.

**Long-command islands** (needs the `PreToolUse` hook, see `INSTALL-HOOKS.md`): when a Claude
Code Bash call runs longer than N seconds (Settings › Developer, default 30), a small capsule
with the command and a clock sits inside the pill; when it finishes, a peek shows the duration
and exit status. For normal terminal commands you can add this optional zsh snippet to
`~/.zshrc` yourself (Glance does not install it). It sends the same events through `glance-hook`:

```zsh
# Glance: long-command islands for normal terminal commands (optional).
zmodload zsh/datetime 2>/dev/null
autoload -Uz add-zsh-hook
typeset -g GLANCE_HOOK=${GLANCE_HOOK:-/Applications/Glance.app/Contents/MacOS/glance-hook}
typeset -g _island_id="" _island_cmd=""
_island_esc() {
  local s=${1//\\/\\\\}; s=${s//\"/\\\"}; s=${s//$'\n'/\\n}; s=${s//$'\t'/\\t}; s=${s//$'\r'/}
  print -r -- "$s"
}
_island_send() { [[ -x $GLANCE_HOOK ]] && print -r -- "$1" | "$GLANCE_HOOK" >/dev/null 2>&1 &! }
_island_preexec() {
  _island_id="zsh-$$-$EPOCHREALTIME"
  _island_cmd=$(_island_esc "$1")
  _island_send "{\"hook_event_name\":\"PreToolUse\",\"session_id\":\"zsh-$$\",\"cwd\":\"$(_island_esc "$PWD")\",\"tool_name\":\"Bash\",\"tool_use_id\":\"$_island_id\",\"tool_input\":{\"command\":\"$_island_cmd\"}}"
}
_island_precmd() {
  local code=$?
  [[ -z $_island_id ]] && return
  local ev=PostToolUse extra=""
  if (( code != 0 )); then ev=PostToolUseFailure; extra=",\"error\":\"Exit code $code\""; fi
  _island_send "{\"hook_event_name\":\"$ev\",\"session_id\":\"zsh-$$\",\"cwd\":\"$(_island_esc "$PWD")\",\"tool_name\":\"Bash\",\"tool_use_id\":\"$_island_id\",\"tool_input\":{\"command\":\"$_island_cmd\"}$extra}"
  _island_id=""
}
add-zsh-hook preexec _island_preexec
add-zsh-hook precmd _island_precmd
```

**Look** (Settings › Look; each has its own toggle):
- **Glow edge**: a soft colour glow around the island edge (Rainbow, Accent or Music colours).
  It rotates slowly while the island is open. On the closed pill it is a subtle, still glow; it
  can be set to rotate there too (uses more GPU). Event states override it: amber pulse while
  Claude needs your OK, green flash when Claude is done, red flash on Deny, accent pulse when the
  timer finishes. Drawn with Core Animation (a conic gradient under a pre-blurred mask), so
  Glance does no per-frame work. It pauses while the screen sleeps or the island is hidden, and
  stays still with Reduce Motion.
- **Colours from the music**: 2–3 dominant colours from the album art (cached per track) tint the
  panel wash, the visualiser bars, the progress bar and the lyric line, and blend smoothly
  between tracks. The accent colour is used when nothing plays.
- **Accent colour**: Coral, Ocean (default), Mint, Violet, Gold, or Match Wallpaper (dominant
  colour of the current desktop picture file, re-checked on Space changes, on wake and every
  10 minutes). Used for the timer ring and play button, selected tab, Done button, chip hover,
  search focus ring and badges. Tuned for both Dark Matte and White Matte.
  Note: Match Wallpaper reads the wallpaper file, so if your wallpaper is in Downloads, Desktop
  or Documents, macOS will ask once for access to that folder.
- **Glass & motion polish**: 1 px glassy top-edge highlight, two-layer depth shadow, slight
  lift when you rest on the closed pill, cards that stagger in, and hover highlights.
- **Trackpad haptics** on Allow/Deny, timer done and Shelf drops. **Soft UI sounds** (off by
  default) use built-in system sounds only (Pop, Tink).

**Cinema mode (Ambilight)** (Settings › Look, on by default; needs the Chrome extension below):
while a video plays in Chrome, the glow around the pill takes the colours of the picture, like LED
strips behind a TV. The left of the glow follows the left of the video, the right follows the
right, the top follows the top band and the bottom follows the centre. Colours are smoothed
(~200 ms) and boosted. **Glow strength** (Subtle / Normal / Rich, default Rich) controls how wide
and deep it is. The visualiser bars follow the video's sound when the page allows it (otherwise
they pulse gently). A short Cinema intro (colour ribbons that fan out and collapse into the glow)
plays when it starts. With **Touch Bar glow** on, the Touch Bar shows the same colours full width;
tap it to get the normal Touch Bar back. **No screen capture is used.**

**Cinema in the pill** (Settings › Look › Cinema; each can be turned off; the pill never grows):
progress line along the bottom edge (and "Ends 11:42 PM" on hover and every 10 minutes), a title
card when a video starts, "Intermission · paused 2 min" with popcorn when paused (up to 15 min),
video controls on hover (back 10 s, play/pause, forward 10 s, picture-in-picture, full screen;
a click elsewhere on the pill still opens the panel), "lit from inside" scene colours, and a faint
full-width sound wave with a bass thump. Glance follows one Chrome video at a time and sends
controls only to that video. Some pages refuse picture-in-picture or full screen from an
extension; full screen then makes the Chrome window full screen instead.

The island hides itself during Mission Control and App Exposé, so it doesn't cover the Spaces bar.

**Glance Chrome extension** (Cinema mode) (`chrome-extension/`, Manifest V3):
- Reads the playing video directly at 32×18 pixels, about 10 times a second (also inside iframes).
- If a page doesn't allow that (a cross-origin video without CORS), it takes a snapshot of only that
  tab with `chrome.tabs.captureVisibleTab`, about twice a second, crops it to the video, computes
  the colours and throws the image away immediately.
- DRM-protected players (Netflix, Prime Video, Disney+) show black to the extension; it reports
  "protected" and Glance uses the accent colour.
- Sound levels come from Web Audio, only for media the page lets scripts read, and only when it
  can't affect the page's own audio.
- Sent to Glance (via Chrome native messaging and `glance-chrome-host`): colour numbers, four band
  levels, play state, full-screen flag and the site's domain. No images, no URLs beyond the
  domain, no page content. Nothing is stored.

**Load the extension:** see "Cinema mode" in the [README](../README.md#cinema-mode-chrome-extension).

**Touch Bar** (Settings › Touch Bar): a **Control Strip button** (capsule icon) shows or hides the
island, and starts Glance if it isn't running. It comes from a tiny helper, `GlanceBar.app`
(inside Glance.app, registered as a login item so it survives restarts). macOS may show a
"Login item added" notification, and lists it under System Settings › General › Login Items.
These use private Touch Bar APIs (as MTMR/Pock do), checked present on macOS 15.6.1.

**Football mode** (Settings › Football): pick a league and a team. Live scores (polled every 6 h, every 30 s only during a match), a live score in the pill, a Home card, a matchday theme in the team colours, a spoiler-free mode, and eleven celebration animations that play inside the pill. Each has a Preview button, and `open glance://play-goal` replays the last goal. Data comes from a pluggable source (`Sources/Island/FootballSource.swift`); the default is ESPN's public site feed, which is unofficial. Club badges belong to their clubs; they are downloaded at runtime and cached on your Mac only, and none are in this repo.

**Desktop dials** (can be turned off in Settings): two round dials on the desktop for volume and
display brightness, with tick-mark rings. Drag around the ring, drag up and down, or scroll to change them.

**Settings window** (gear icon): toggles for each feature, launch at login, weather units and
manual city, theme options, wallpaper pair, timer length, quick-launch apps, clipboard and shelf options.

## Permissions it asks for

Each is asked once. Glance's code signature uses a fixed designated requirement
(`identifier "app.glanceformac.glance"`), so permissions you grant stay valid after rebuilding.

| Permission | When | Why |
|---|---|---|
| Location | First launch | Local weather. If you deny it, type a city in Settings. |
| Calendars (full access) | First launch | Next event on the Calendar card. |
| Automation → System Events | First click on the theme button | Switch macOS Light/Dark mode. |
| Automation → Spotify / Music | Only if the system-wide media method stops working | Fallback media controls. |
| Accessibility | Only if you turn on "Paste into the front app" | Simulating ⌘V. |
| Files in Desktop / Documents / Downloads | Possibly, if Shelf files live there and you open them later | Re-resolving Shelf bookmarks after a restart. Dropping a file is fine. |
| Login Items approval | If you turn on Launch at login | macOS may ask you to approve it in System Settings › General › Login Items. |

Glance uses no screen-capture API at all; Cinema mode gets its colours from the Chrome extension.
The camera is used only by the Mirror, and only while the Mirror page is open.

| Camera | First time you open the Mirror | Live mirror preview; nothing is recorded |

## Data sources and credits

- **Now Playing**: [mediaremote-adapter](https://github.com/ungive/mediaremote-adapter) by Jonas van
  den Berg and contributors, **BSD 3-Clause** licence. Vendored unmodified in
  `Vendor/mediaremote-adapter` (licence included and also copied into the app bundle). macOS 15.4+
  blocks third-party apps from the private MediaRemote framework; this adapter runs it inside
  `/usr/bin/perl`, which macOS entitles to it. Glance launches the adapter under a tiny `sh`
  supervisor so it always exits when Glance exits, even after a crash. Fallback: Spotify and
  Apple Music distributed notifications plus AppleScript controls.
- **Lyrics**: [LRCLIB](https://lrclib.net) public API (`/api/get` with artist, track, album, duration).
  Synced LRC lyrics, cached in `~/Library/Caches/Glance/lyrics` (misses are cached too).
  Nothing is shown if there are no synced lyrics.
- **Weather**: [Open-Meteo](https://open-meteo.com) forecast API and geocoding API (free, no key),
  refreshed every 30 minutes. City name via Apple's CLGeocoder.
- **Calendar**: EventKit. **Location**: CoreLocation. **Volume**: CoreAudio (listener-based, no polling).
- **Brightness**: the private `DisplayServices` framework (`DisplayServicesGetBrightness` /
  `SetBrightness`), loaded with `dlopen`. Checked on a MacBookPro17,1: it works. If it ever
  fails, the brightness dial and icon are hidden automatically.
- SF Symbols and SF Pro are Apple system resources.

## Performance

Measured on an M1 MacBook Pro (8 GB), release build:

- Glance at idle: about 23–33 MB RSS and 0.0% CPU (`ps -o rss,%cpu`; physical footprint about 17 MB).
- Now Playing adapter (perl): about 5–10 MB RSS and 0.0% CPU at idle.
- No tight polling. Everything is event-driven (NSWorkspace, IOKit, CoreAudio, EventKit,
  distributed notifications, mouse-event monitors, a Unix socket). Timers: weather every 30 min,
  calendar at the next event boundary, clipboard change counter every 0.5 s, brightness every 3 s
  only while the desktop dials are shown, lyrics and progress only while the island is open and music plays.
- The audio-bar visualiser is a Core Animation layer animation that runs in the system render
  server, so Glance itself does no per-frame work for it.

## Known limitations

- **Frosted glass**: with **Reduce transparency** turned on (System Settings ›
  Accessibility › Display). macOS then draws every translucent material as opaque, so Glance
  respects that and uses a matte gradient. Turn Reduce transparency off and the panel and dials
  become frosted glass automatically.
- **Focus / Do Not Disturb** has no public API. Glance watches
  `~/Library/DoNotDisturb/DB/Assertions.json`, which reliably shows Focus modes you turn on by
  hand. Scheduled or automatic Focus modes may not show up there. If the file can't be read,
  Settings says so, and the peek simply never appears.
- **Password-manager filtering** looks at which app is in front when something is copied.
  Browser-extension copies are only skipped if the extension marks them as concealed (1Password
  and Bitwarden normally do).
- **Shelf drag detection** watches the system drag pasteboard while you drag near the top centre
  of the screen. Dropping directly onto the open Shelf tab always works.
- Glance sits on the first (menu bar) screen only.

## Testing switches (development only)

- `--no-permissions` (or `GLANCE_NO_PERMISSIONS=1`): never asks for Calendar, Location, Automation
  or Accessibility; shows demo weather and calendar instead.
- `--debug`: enables a local test channel (`Scripts/glance-debug.swift`) used to drive states and
  render Glance's own views to PNG (in-process, no screen capture). It is off unless you pass the flag.
- `Scripts/shelf-add.swift`: puts files on the Shelf as bookmarks. Run it only while Glance is quit.

## System and media

- **Live Activities**: small capsules beside the pill (never changing its shape) for the focus timer and a live match when the pill is busy, Claude runs, Clean keyboard, and anything else. Other code uses `ActivityCenter.start/update/end`. Scripts: `Scripts/glance-activity.sh "npm test" npm test` shows a long command (socket event `IslandActivity` through `glance-hook`).
- **Camera and microphone guard**: green (camera) / orange (microphone) dot on the pill and a peek. Camera state comes from `IslandContext`. Microphone clients come from CoreAudio process objects, so the app name is exact; camera names are a best guess (frontmost app) because macOS has no public per-app camera list.
- **Sound** (speaker icon): output and input pickers, volume, AirPods/Bluetooth connect peek with battery (from `system_profiler`), optional volume/brightness peeks (the macOS HUD may still appear), optional Caps Lock peek (Input Monitoring). No per-app volume.
- **System tab**: Screenshots (watches the screencapture location, thumbnails, drag out, Quick Look, on-device OCR search, new-screenshot peek; files are never touched), Monitor (CPU, memory, disk, network, battery health/cycles/temperature, sampled every 2 s only while visible), Tools (display off, lock via Ctrl+Cmd+Q or screen saver, Clean keyboard 60 s with hold-Esc exit), Rings (opt-in counts only), Stocks (opt-in, Yahoo Finance).
- **Clipboard extras**: 1 to 9 quick paste, colour swatches, plain text, links without tracking (utm_*, fbclid, gclid...), AirDrop from Shelf, screenshots and clips.
- **Window snap zones** (opt-in, needs Accessibility) and an optional **desktop pet** (off by default).

### Measuring idle CPU

Run Glance, close the panel, leave the machine quiet, then `Scripts/measure_idle_cpu.sh [pid] [seconds]`. It runs `top -l N -s 2 -pid PID`, drops the first sample and prints mean/max CPU and RSS. Budget: 0.0 to 0.3% idle.
