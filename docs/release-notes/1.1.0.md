# Glance 1.1.0

## Updating from 1.0.0

Glance 1.0.0 has no built-in updater, so update once by hand:

- Installed with Homebrew: `brew upgrade --cask glance`
- Installed with the install script: run the same install command again

From 1.1.0 on, Glance updates itself.

## New

- **Updates inside the app.** Glance checks for a new version once a day, and you can check any
  time from the menu bar icon, Settings or the command palette. Updates are signed, so only
  real Glance releases install.
- **A character in your notch.** Pick Mochi, Kitsune or Pocket ninja in Settings > Character.
  It reacts to what you are doing: it naps when you are away, moves to your music, slips away
  when a video goes full screen, catches files you drop on the Shelf, and waits next to Claude
  Code when it needs your OK. You can also add your own character packs (a folder with a
  manifest.json and its art).
- **Shadow Clones.** While Claude Code runs helper agents, a small clone appears beside the
  character for each one and clears when it finishes.
- **Claude Code setup guide.** The approval card, character reactions and Shadow Clones need a
  few Claude Code hooks. Glance never edits your Claude settings: follow the short guide in
  INSTALL-HOOKS.md (also linked from Settings > Claude Code) to add them by hand, check they
  work, and remove them.
- **Touch Bar strip.** On Macs with a Touch Bar, the character, Claude's status and Approve /
  Deny buttons show there too.
- **Settings sidebar.** Every Settings page is one click away.
- **New app icon.**

## Better

- **Clipboard history ignores noise.** Dictation, password managers and other apps you choose
  are left out, and repeats and single-character copies are skipped.
- **Shelf tidies itself.** When you drag a file out of the Shelf it leaves the Shelf (with a
  5 second Undo). Pinned items stay. You can turn this off in Settings.
- **Claude Code approval card** shows the character at a comfortable size, with nothing cut off.
- **Lower CPU use when idle.** (confirm)
